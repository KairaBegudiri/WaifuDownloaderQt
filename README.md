# WaifuDownloaderQt
 A QT application that downloads images of waifus/nekos based on https://waifu.im and https://nekos.moe

### Requirements

* qt6-base-dev 
* libcurl4-openssl-dev 
* cmake

### Build
```bash
mkdir build && cd build
cmake ..
make
./waifudownloader
```

## About WaifuDownloaderQt
